Introduction

Missing PowerToys Quick Accent on Linux? This is the solution!
Type German umlauts (ä, ö, ü, ß) using the exact same hold + space gesture.

View on GitHub Installation Guide

Like PowerToys Quick Accent, but Better

  • Same intuitive gesture (hold letter + space/arrow keys)
  • Accent Cycling: Press leader key repeatedly to cycle through variants (á → à → â → ã)
  • Snippets: Map single keys to entire text phrases
  • Emoji mappings for quick insertion
  • No clipboard interference (unlike many Linux alternatives)
  • Works system-wide on X11 and Wayland
  • 20 customizable character mappings with cycling support

Features

Accent Cycling

Press leader key repeatedly to cycle through variants: é → è → ê → ë

Snippets

Map single keys to entire phrases: g → "Guten Tag" (no commas allowed)

Emoji & Symbols

Quick insertion of emojis, math symbols (∞, √, π, Δ, Ω, ∑) and special characters

No Clipboard Usage

Direct text insertion via commitString() - your clipboard stays untouched

X11 + Wayland

Native support for both display protocols, no root permissions needed

Fully Configurable

20 mapping slots, custom delays, flexible leader keys (Space/Arrows)

How It Works

  1. 1

    Hold Letter

    Press and hold a, o, u, or s

  2. 2

    Press Space

    Within 400ms, press Space (or configured leader key)

  3. 3

    Get Umlaut

    Output: ä, ö, ü, or ß

  4. 4

    Cycle (Optional)

    Press Space again to cycle: á → à → â
